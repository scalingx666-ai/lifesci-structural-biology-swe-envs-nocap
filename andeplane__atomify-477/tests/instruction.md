## Problem
Ten bundled moltemplate examples (proteinfolding, benzene, methane, water_nacl, …) declare input scripts like `run.in.npt` or `run_short_sim.in.nvt`. `isScriptFile` only accepted `in.*` and `*.in`, so after "Use as project" those files had no Run / Set-as-input buttons or LAMMPS highlighting, and Run simulation discarded the designated script (falling back to `system.in` or "no scripts"). Quick run was unaffected.

## Fix
- `isScriptFile` also accepts `*.in.*` names (moltemplate's convention).
- `isScriptFile(path, inputScript?)`: the project's designated input script always counts as a script. Used in the Files tab, editor, Run simulation, the New run modal and project creation.
- Tests for accepted/rejected names and the designated-script rule.

Checked locally: `vitest run` (665 passed), typecheck, prettier, eslint.
