**Title:** Interaction Fingerprints

## Description

Added fingerprints module. Two type of fingerprint has been implemented. The first one is called PyPLIF, more information at 'https://code.google.com/archive/p/pyplif/'. The second one is SiLIRID,  based on 'http://dx.doi.org/10.1016/j.csbj.2014.05.004'. Also added new features to ring_dict, "resnames" and "resid".
