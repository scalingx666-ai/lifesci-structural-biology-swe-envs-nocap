## Summary
- **Dark by default:** new `overrides.json` in the lite dir sets `JupyterLab Dark` as the default JupyterLite theme. `jupyter lite build` picks it up (`settings:patch:overrides`). Users who explicitly chose a theme keep their choice.
- **No reload on tab switch:** `NotebookTab` is now rendered by the Shell instead of `ProjectWorkspace`. Once a project's notebook is opened, the iframe stays mounted (hidden with `display: none`) while you're on Files/Runs or other screens, so the JupyterLab session and Pyodide kernel survive. The iframe URL is captured once per project, so file-list refreshes never change `src`. Opening another project's notebook replaces it.
